# پروژه چت‌روم امن با سوکت و SSL/TLS (پیاده‌سازی به زبان پایتون)

این پروژه یک سیستم چت‌روم چندکاربره (Multi-Client) امن بر پایه پروتکل TCP و لایه امنیتی SSL/TLS است.

* **بخش کلاینت (Client):** عبدالرضا میرزامحمدی - شماره دانشجویی: 4021522935
---

## ویژگی‌های پیاده‌سازی شده در کلاینت (`client/client.py`)
* **ارتباط امن SSL/TLS:** استفاده از ماژول `ssl` پایتون جهت رمزنگاری ترافیک شبکه.
* **رابط کاربری تعاملی (CLI Multi-threading):** مدیریت ناهمگام دریافت و ارسال پیام با ترد مجزا.
* **فرمت تبادل داده JSON:** ارسال و دریافت ساختاریافته درخواست‌ها و پاسخ‌ها.
* **سیستم اتصال مجدد خودکار (Auto Reconnect):** تلاش برای بازیابی ارتباط در صورت قطعی شبکه.
* **دریافت پیام‌های غیبت (Missed Messages):** دریافت تاریخچه پیام‌های ارسال شده در زمان قطعی پس از اتصال مجدد.
